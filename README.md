# Лабораторная работа №1

## Установка
```shell
git clone https://github.com/maharlabo/lab1.git
cd lab1
python -m venv .venv
.venv/Scripts/activate.ps1
pip install -e .
```

## Команды
Чтение файла и запись информации в json:
```shell
python -m streamstats analyze INPUT [INPUT ...] --format csv|jsonl --output REPORT.json
```

Чтение файла с игнорированием ошибочных строк:
```shell
python -m streamstats analyze INPUT --format jsonl --skip-invalid
```


## Что реализовано:
1) Построчное чтение файла cvs или jsonl
2) JSON - отчёт содержит следующее:
   - Общее число событий
   - Количество событий каждого уровня
   - Количество события каждого источника
   - ТОП-5 источников ошибок уровня ERROR/CRITICAL
   - Первая и последняя временную метку.

## Что может привести к ошибке:
1) Передача пустого файла
2) Передача файла с повреждёнными строками (за исключением использования параметра --skip-invalid) (Также в csv допускается перенос строки, если значение находится в кавычках)
3) Ошибочная временная метка в строке (за исключением использования параметра --skip-invalid)
